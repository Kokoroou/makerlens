What the tools do

They do

Read only the files you select, on your own device. Reverse the game’s own obfuscation in browser memory, using the key that ships with the game or the archive.

They never

Upload, store or transmit any file or key, or tell us which files or games you open. They only read: your game is never modified, and MakerLens Events is read-only too.

RPG Maker MV and MZ keep an XOR key in plaintext in data/System.json, which ships with every game deployment; the tool reads it from your local filesystem, reverses the XOR in browser memory and shows the result through a temporary Blob URL. XP, VX and VX Ace pack assets into an archive (.rgssad, .rgss2a, .rgss3a) whose key is embedded in the archive itself.

Because the keys are co-located with, or embedded in, the content they “protect”, this obfuscation is not considered effective access control under most legal interpretations, and is substantially different from true DRM systems. The only automatic network requests are described on the privacy page.

Intended use

  • Game developers working on their own RPG Maker projects who need to inspect or recover their own assets.
  • Artists and contributors who created assets for a game and need to review or retrieve their own work.
  • Modders operating under explicit permission from the game’s copyright holder.
  • Researchers and educators studying file formats or game development workflows.

Not for

  • Extracting, distributing or repurposing assets from games you do not own or have not received explicit permission to modify.
  • Circumventing access controls on commercially distributed games without authorization.
  • Any use that violates the End User License Agreement of the game or the RPG Maker engine.

Your responsibility

  1. You are responsible for ensuring you have the legal right to access and process the files you select.
  2. The tools do not grant you any rights over third-party copyrighted content.
  3. The authors of the tools are not liable for how you use the output.

Copyright and licences

Game assets (images, audio, scripts) distributed with a game are protected by copyright regardless of whether they are obfuscated. Decrypting them for personal inspection does not create a licence to redistribute them.

Kadokawa / Gotcha Gotcha Games publish a separate EULA for each RPG Maker version. Consult the one that applies to the game you are working with; common restrictions include limits on asset redistribution and derivative works.

The source code of MakerLens Assets and MakerLens Events is open source under the MIT licence (see the links above). The projects ask contributors not to commit real game assets or game data, even as test fixtures, without permission from the copyright holder.

Takedown requests

If you are a rights holder and believe a tool is being used to infringe your copyright, please open an issue or contact the maintainer directly (Kokoroou on GitHub). We will respond promptly. A takedown request directed at a repository must target the tool itself, not individual users’ actions, which are outside the project’s control.
