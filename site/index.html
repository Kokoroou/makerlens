MakerLens Assets

Every image and sound in the game, in one grid

Preview the images and audio of a game, encrypted or not: .rpgmvp, .png_, .ogg_, .rgss3a, .xyz and more. Filter by image size or audio length, and set aside files that are copies of one another. For modders and translators, and creators recovering their own work.

What it does

Key read from the game

MV and MZ keep it in System.json, archives carry their own. Nothing to type.

Duplicates by content

A SHA-256 of the decrypted bytes finds identical copies. One switch hides them.

Filter by size or length

By pixel size or audio length. Only headers are read, never the whole file.

How it works

You pick a folder. The page reads it. That is all

The browser reads the files with the File API and everything is decoded on your device, in memory. There is no upload and no server copy, and the page’s security policy limits which hosts it can reach.

The three steps

  1. Pick a folder

    Choose the game’s root folder, an archive such as Game.rgss3a, or paste a game link.

  2. Decode in memory

    The key is read from the game itself. Nothing is written back and nothing is kept after you close the tab.

  3. Look, filter, save

    Browse, search and play. Download only what you choose to keep.

  • Local only
  • Works offline
  • Free and open

Common questions

Before you open a folder

How do I open .rpgmvp, .png_ or .rgss3a files?

Select the game folder in MakerLens Assets. The key is read from the game itself.

  • 2000 and 2003 games: .xyz images.
  • XP, VX and VX Ace archives: .rgssad, .rgss2a, .rgss3a.
  • MV and MZ games: .rpgmvp, .png_ and audio files.
  • Preview the images and audio, then download them one by one or as a ZIP.
Can I see a game’s dialogue, choices and switches without the editor?

Yes, in MakerLens Events. It is read-only.

  • Opens the data of a released RPG Maker game, from 2000 to MZ.
  • Draws each map or common event as a flow graph.
  • Fills in switch, variable and actor names.
  • Lists scenes with pictures and dialogue that you can play.
  • A save file lets a scene start from your own progress.
Are my game files uploaded anywhere?

No. The browser reads and decodes your files on your device.

  • The only data sent is anonymous: a counter of page views and of a few actions, by name.
  • It never records what you open.
  • Details are on the privacy page.
Which RPG Maker versions are supported?

Both tools support 2000, 2003, XP, VX, VX Ace, MV and MZ.

  • Use them for games you own, or with the rights holder’s permission to inspect.
  • They are not for repackaging or redistributing a game.
  • Read the Legal page.
Do I need to install anything? Does it work offline?

No install and no account are needed.

  • Desktop Chrome, Edge, Firefox and Brave work best.
  • Phone browsers may not offer folder selection.
  • Once a page has loaded, it keeps working without a connection.
Can I open the same game in both tools?

Yes. The folder stays on your device.

  1. Open a game folder in Chrome or Edge.
  2. Click the Assets | Events switch in the header.
  3. The other tool opens the same folder without asking you to pick it again. The browser may ask once more for permission.
