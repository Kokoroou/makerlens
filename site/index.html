Common questions

How do I open .rpgmvp, .png_ or .rgss3a files?

Use MakerLens Assets. Select the game folder (RPG Maker MV or MZ) or a .rgssad, .rgss2a or .rgss3a archive (XP, VX, VX Ace). The key is read from the game itself, so you can preview the images and audio and download them one by one or as a ZIP.

Can I see a game's dialogue, choices and switches without the editor?

Yes. MakerLens Events opens the data of a released RPG Maker MV or MZ game and draws each map or common event as a flow graph, with switch, variable and actor names filled in. It is read-only.

Are my game files uploaded anywhere?

No. The browser reads the files on your device and everything is decoded there. The only anonymous data is a page-view counter; see the privacy page.

Which RPG Maker versions are supported?

Assets: MV, MZ, XP, VX and VX Ace. Events: MV and MZ. Both tools are meant for games you own or have the rights holder's permission to inspect, not for repackaging or redistributing a game.
