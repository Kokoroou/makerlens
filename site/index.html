Common questions

How do I open .rpgmvp, .png_ or .rgss3a files?

Use MakerLens Assets. Select the game folder: MV, MZ and archive-based games (.rgssad, .rgss2a, .rgss3a: XP, VX, VX Ace) all open from it, and so do 2000/2003 games with their .xyz images. The key is read from the game itself, so you can preview the images and audio and download them one by one or as a ZIP.

Can I see a game's dialogue, choices and switches without the editor?

Yes. MakerLens Events opens the data of a released RPG Maker game (any version from 2000 to MZ) and draws each map or common event as a flow graph, with switch, variable and actor names filled in. Events that show pictures with dialogue are listed as scenes you can play, and a save file lets them start from your own progress. It is read-only.

Are my game files uploaded anywhere?

No. The browser reads the files on your device and everything is decoded there. The only anonymous data is a page-view counter; see the privacy page.

Which RPG Maker versions are supported?

Both tools: MV, MZ, VX Ace, VX, XP, 2000 and 2003. Both are meant for games you own or have the rights holder's permission to inspect, not for repackaging or redistributing a game.

Can I open the same game in both tools?

Yes. After you open a game folder in Chrome or Edge, the Assets | Events switch in the header carries it to the other tool without picking it again. The folder stays on your device; the browser may ask once more before the other page can read it.
